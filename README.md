# 🩺 Diabetes Prediction & Unsupervised Machine Learning Analysis

## 📌 Project Overview

This project focuses on **Diabetes Prediction and Unsupervised Machine Learning Analysis** using patient-related data.

The main objective is to explore the dataset, perform data preprocessing, apply machine learning techniques, and investigate patterns that can support diabetes-related data analysis.

The project includes two Jupyter notebooks covering diabetes data exploration and machine learning analysis.

## 🎯 Objectives

- Explore and understand the diabetes dataset.
- Perform data preprocessing and cleaning.
- Apply exploratory data analysis (EDA).
- Develop machine learning models for diabetes prediction.
- Apply unsupervised learning techniques to identify hidden patterns.
- Evaluate and interpret the obtained results.

## ⚙️ Installation & Usage

Clone the repository:

```bash
git clone https://github.com/najet-ben-abi-ellotef/Diabetes-ML-Project.git
```

Navigate to the project directory:

```bash
cd Diabetes-ML-Project
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn kagglehub jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebooks located in the `notebooks/` directory.
